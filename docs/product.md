# AutoFE 产品层：交付承诺、里程碑与执行路线

状态：当前事实（就地重写，不带历史叙事；历史见 `.scratch/` 工作记录）。
溯源：交付承诺与验收判据源自用户确认（2026-10 记录于 62 号工作票据，迁入本文件作为唯一家）。执行路线在 2026-10 依据「先修错、再加能力」的用户指示重排。

## 1. 承诺（commitment）

- **受众与产物**：单用户自用的策展画廊产品——把在册真实站点语料（当前 40 页）投影为可读、忠实、**像样**的前端形态，供用户审看与验收；非对外发布物。
- **开放度**：闭式（closed）——不接纳外部贡献；发布/公开需用户另行授权。
- **质量门槛**：既有门禁全部通过是必要条件，不是充分条件；整页体验、源站/图片对照与独立技术/体验复核不可被几何检查或门禁替代。

## 2. 验收判据（acceptance，用户确认）

- 有意义、连贯的端到端页面；表单类页面版式对齐；紧凑的实用导航/页脚；前景/背景对比成对；图片/标题/动作分组连贯；可读的信息密度；无不必要的巨型品牌标题；品牌适宜的变化，不一律居中/不无谓重设计。
- 页面类型要有其**应有的构图**：首页/落地页有焦点与节奏，目录页是可视网格而非链接目录，文章页有居中阅读列，feed 有主列+侧栏，个人页有身份卡。
- 度量宽度 2560 / 1920 / 1440 / 390px；保留事实与动作、闭式语法；无站点级 CSS/模型表现逃生口、无图片放大、无编造的源站事实。
- 相关处做全量源站/图片对照；实际整页高度目检；哈希绑定的自证 + 全新独立上下文的技术/体验复核；交付物为「原站 | 渲染」并排图。

## 3. 唯一用户交付里程碑（已确认，不得增删移动）

**全部在册策展页面按上述判据优化/验证完毕 + 站点身份标题修复 + 一个供人审看的聚焦画廊，经独立复核后交付用户。** 期间不设中间用户关卡，不做例行进度汇报。

## 4. 当前状态（里程碑未达成）

- 语料基线 **40 页**（36kr 首页/科技频道、apple iphone-16、stripe-dashboard login 因反爬/503 不可再采而退役；新增 apple airpods-pro、sspai login）。
- **机械门禁全绿**（渲染/HTML/Markdown 保真 40/40、46 模型校验、17 道门禁+自测、视觉自查 40/40、证据哈希一致），且已通过一次独立技术验收。
- **但该验收只覆盖「结构与事实忠实」，未覆盖构图与设计**。用户全页审看后判定：多数页面「结构忠实、版面为零」，不满足 §2 的构图判据。**因此里程碑未达成**；既有「门禁全绿/验收 ACCEPT」不构成交付。
- 缺陷的根因是引擎缺「构图」层并将页面原型静默回落为 `default`（40 页中 32 页），以及 CSS 覆盖自身声明（详见 `docs/m1/composition.md` §6）。

## 5. 执行路线（先修错，再加能力；全部为内部里程碑，唯一用户关卡仍在 §3）

1. **S1 引擎诚实性（修错）**：构图完备（消灭静默 `default`）+ 意图校验门禁（未定构图 / 死选择器 / 级联覆盖）+ 移除覆盖声明的 CSS 上限。
   - 判据：门禁用当前已知缺陷做负样本**全部抓到**；40 页页面原型全部非 `default`；结构选择器 0 死代码；声明意图 0 被覆盖。
2. **S2 构图框架**：band hero、feed+aside、卡片网格、居中阅读列、mosaic 照片墙落地；媒体按角色定尺寸。
   - 判据：10 页样板（当前缺陷页）并排图显示正确构图；不再出现白洞/左侧死区/条目化目录；高度比例回到合理区间。
3. **S3 设计语言**：字阶（标题 ≥2.5–3×）、中文行长（≈36em 而非 74ch）、间距节奏（8pt）、留白与焦点；颜色/字体 token 有据可依（非凭空选色）。
   - 判据：10 页样板通过排印/层级/留白检查（`typography`/`critique` 口径）。
4. **S4 铺开与交付**：10 页样板方向确认后铺到 40 页，重跑全部门禁 + 新独立验收（技术 + 体验），产出「原站 | 渲染」聚焦画廊，按 §3 交付。

- 顺序不可交换：S1/S2 是「修错」，先于 S3 的「加能力」；S4 的最后一次独立验收不可由前序门禁替代。

# 组 3 质量评审（审美/可用性）

审查对象：`m1/curated/renders/<k>.png`（当前渲染产物）；需要判断"源站是否如此"时对照 `corpus/<k>/full.png` 的局部裁切。
只读评审，未改任何文件。图片预算 12 张，逐页记录"我亲眼看到什么"。

## stripe-dashboard/login
- [major] 现象：整页内容挤在左上一小块——表单列从 x≈110 到 x≈420，**右侧约 2/3 宽度与下方约 2/3 高度全是空白**；一条 `<hr>` 分隔线却横贯到 x≈1170，比表单本身宽 3 倍。｜为什么说不过去：真实登录页（Stripe 自己也是）把表单居中放进卡片，这里读起来像"骨架屏没加载完"，分隔线比内容长更是明显做错。｜建议：登录块居中（或整体收成一张卡片），分隔线宽度约束到内容列宽。｜层级：renderer
- [major] 现象：两个输入框左边缘**不对齐**——"邮件地址"标签较宽，其输入框左边缘在 x≈285；"密码"标签较窄，输入框左边缘在 x≈190。两个框一高一低错开。｜为什么说不过去：表单字段左对齐是基本排版常识，这里看起来像随手摆的。｜建议：label 与 input 改为上下两行（label 在上、input 占满列宽），或给 label 固定宽度使 input 左对齐。｜层级：renderer
- [major] 现象："在此设备上记住我"这个 **checkbox 被套在一个圆角描边方框里**（x≈115–290），看起来像一个 chip/按钮，里面再放个小方框。｜为什么说不过去：勾选项不该长得像可点按钮，"能点的地方"与"控件"混淆。｜建议：去掉外框，渲染成普通 label+checkbox 行。｜层级：renderer
- [major] 现象：**主次完全一样重**——"登录"（主操作）、"忘记密码？"、"Google/通行密钥/SSO"、"创建账户" 全是同一种浅色描边胶囊，大小、颜色、圆角一致。｜为什么说不过去：读者扫不出哪个是主 CTA，"所有东西一样重"正是最像机器拼的地方。｜建议：submit 用实心主按钮，其余降为文字链接/次级按钮。｜层级：renderer
#### 总评一句话：把表单居中收窄成一张卡片、输入框对齐、主按钮做实心，这页就成立了。

## aliyun-com/product-ecs
- [major] 现象：四张实例卡（e实例/u2a实例/c9i实例/g9i实例）里**第 4 张 g9i 少了价格行**——前三张是"名称/¥价格/卖点/立即购买"，g9i 只有"名称/中大型企业首选/立即购买"，于是它的"立即购买"按钮比另外三个**高出约 30px**，四个按钮不在同一水平线。｜为什么说不过去：并列四张卡按钮不齐，一眼就看出是拼坏了的网格。｜建议：卡片内容槽位对齐（缺价格时留占位），或按钮统一贴卡片底部对齐。｜层级：renderer（对齐）+ model（g9i 缺 `_price`）
- [minor] 现象：价格说两遍——卡头"¥99"下面紧接着"个人开发者必选 · ¥99.00/月"（u2a/c9i 同样）。｜为什么说不过去：同一信息重复且第二个还带小数点，显得啰嗦、像模板拼接。｜建议：卖点行去掉金额，或卡头不再单独印 `_price`。｜层级：model
- [minor] 现象："已为全球 500 万客户提供算力服务。" 之后是两行**孤立短行**："29 地域"、"90 可用区"，无标签结构、字号与上下文一致。｜为什么说不过去：两个裸值夹在正文里，读者不知道它们是统计还是导航。｜建议：并成一条带标签的 meta（如"29 地域 · 90 可用区"）或做成三格数据条。｜层级：model
- [minor] 现象：页尾"产品动态" 4 条列表之后，**孤零零一个深色实心"立即购买"按钮**，周围没有任何标题/说明。｜为什么说不过去：根动作落在新闻列表后面，位置和上下文对不上，看起来像多余的悬浮按钮。｜建议：把根 CTA 提到页头 hero 或实例卡区，不要丢在页尾。｜层级：model/renderer
- [通过] "高稳定性/极致性能/安全可靠/高性价比" deflist 两栏对齐、实例卡 4 列网格、CPU/内存属性行与上方列对齐——这部分层级与排布是成立的（也确认此前 "buy 英文动词" 已改为中文"立即购买"）。
#### 总评一句话：把四张卡的按钮对齐、去掉重复价格，网格就不像拼坏的了。

## huawei-cn/search-laptop
- [major] 现象："类别"筛选组是一个**描边大框**，里面 5 个 radio（全部(80)…新闻与活动(12)）只占到 x≈1100，**框却一直拉到 x≈1210，右侧留约 210px 空框**。｜为什么说不过去：容器比内容大一圈、右边空一块，是典型的"宽度由容器而非内容决定"，一眼假。｜建议：筛选组容器宽度贴合内容（inline-block / fit-content），或让选项均匀铺满。｜层级：renderer
- [major] 现象：筛选框下方**孤零零一个蓝色胶囊**（x≈120，单独一行，上下各留大片空白），文案与源站左侧"类别"标题同行的**红色小字"重置"**对应。｜已对源：源站把"重置"做成紧贴"类别"标题右侧的小号红色文本链接；渲染把它拎出来、换成蓝色描边胶囊、单独成行。为什么说不过去：一个重置入口飘在筛选区下方、还长得像主筛选 chip，读者读不出它是什么；样式层级也错（文本链接→显著胶囊）。｜建议：把"重置"放回"类别"标题右侧、用文本链接样式。｜层级：renderer/model
- [major] 现象：顶部**搜索框没有提交按钮**——渲染里只有左对齐的"请输入关键字"小输入框（宽约 345px）；已对源：源站搜索框**居中、约 730px 宽，右侧带放大镜提交按钮与清除(×)按钮**。｜为什么说不过去：搜索页丢了提交控件、且从居中大框缩成左上小框，看起来像半成品。｜建议：恢复居中搜索框 + 提交按钮。｜层级：renderer
- [major] 现象：**结果列表形态与源站完全不同**——源站是**单列**结果流：每条 = 面包屑 URL（如 `consumer.huawei.com/cn/laptops/`）+ 蓝色标题 + 摘要 + 来源，无卡片边框；渲染改成**三列描边卡片网格**，且丢掉了面包屑 URL 与顶部"相关性"排序选择器。｜为什么说不过去：搜索结果是有序列表（应按 layout-axes 堆叠），不是可对照的同形实例；改成三列卡片 + 丢 URL/排序，读者会觉得"这不是华为搜索页"。｜建议：结果恢复单列堆叠、保留面包屑 URL 与排序控件。｜层级：renderer/model
- [minor] 现象：11 张结果卡每张都以"来源：消费者业务网站"结尾，**同一句话重复 11 遍**。｜为什么说不过去：重复元信息占版面、无信息量。｜建议：来源相同时上提为列表级说明，或只在有差异时显示。｜层级：model
- [minor] 现象：每张卡标题都是**蓝色+下划线**（双重链接样式）。｜为什么说不过去：下划线铺满每一行标题，视觉很吵；真实搜索页通常只有悬停才下划线。｜建议：标题仅用品牌蓝、去掉常驻下划线。｜层级：renderer
#### 总评一句话：把"重置"放回"类别"旁、搜索框恢复居中带按钮、结果恢复单列，这页才像华为搜索。

- [minor] 已对源·证实：源站 "This service is optional." 是**带左侧灰竖条的 callout**（缩进提示块），渲染拉平成普通正文行，提示感丢失。｜层级：renderer
- [minor] 现象：H1"Register a birth abroad" 与紧随其后的引导段 "You must register your child's birth…" 字号非常接近，引导段看起来像第二个标题。
- [minor] 现象：所有按钮（approved translator / apply for a UK passport / Start now）都是近黑色实心；已对源：真 GOV.UK 的 Start now 是**品牌绿 + 箭头**。｜为什么说不过去：品牌色未落地（M1 中性品牌，可接受，但记 minor）。｜层级：renderer/brand
- [通过] "Explore the topic" 主题胶囊、Related content 列表、标题层级（H2/H3）整体结构与真 GOV.UK 高度一致，是四页里最像真产品的。
#### 总评一句话：给正文加阅读宽度上限、把句内链接放回句内，这页就几乎能以假乱真。

- [major] 现象："Which iPhone is right for you?" 五个机型块里，每个规格子块（display/battery/chip/camera/front）**只印值、不印属性名**——读者连着看到 "Up to 44 hours video playback…""A20 Pro chip · 6-core CPU · 7-core GPU…" 等无标签长句，无法知道哪行是续航、哪行是芯片。｜证据：`m1/curated/apple-com/iphone-16.json:433-610` 各子块形如 `battery: { _detail: {…} }`，无 label 角色，renderer 只输出 `_detail` 文本。｜建议：输出属性名（Battery/Chip/Camera/Front），或按 layout-axes §2 走对比表。｜层级：renderer/model
- [minor] 现象：价格说两遍——"From $799 or $33.29/mo. per month for 24 mo." 下一行又是大号 **"$799"**；且首行把 "/mo." 与 "per month" 两种写法叠在一起。｜为什么说不过去：同一数字两种写法叠出、单位重复，像拼接残留。｜建议：只留一处价格，修掉 "/mo. per month"。｜层级：model/renderer
- [minor] 现象："Save for later" 与 "Continue" 两个 CTA **竖排两行浅色 chip**、左对齐。｜为什么说不过去：主/次判断不出来，Continue 不像主行动。｜建议：并排、主次分明。｜层级：renderer
- [通过] 六步配置流程按 F-031 堆叠、每块自带标题；此前"Continue/Save for later 被渲染成整幅横幅"的问题已修为 chip 链接。
#### 总评一句话：把五个选择框贴合内容、给规格行补属性名，这页立刻不"骨架"了。

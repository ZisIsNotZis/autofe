## 3. 缺口归因（M2 最有价值的产出）

**MODEL 缺口 = 编码失败，不是语言上限**（IR 已有原语，编码器没用）：
- stripe：争议受理费/抗辩费 HK$85 两个金额、非卡费率 2.2%+HK$2.00 未编码 → **已补**
- aliyun：实例价格（¥99/¥1,238/¥1,385 每月）未编码 → **已补**
- sspai：两个方案的真实方法内容被错误塞进 `_intent` 字符串；related 捏造"同一作者"+ 悬空 URL → **已修**
- linear：beat 正文、logo 墙、CTA 文案未抽取 → **部分补**（logo 墙 5 家、Get started/Contact sales）；beat 正文需重抓时增强文本抽取
- apple：决策支持章节（机型对比表/FAQ）不在建模范围 → **已声明，维持**

**RENDERER 缺口 = 引擎 prior 库的输入**：
- ~~`_intent` 作为可见内容输出（全页面系统性问题）~~ → **已修**（改 HTML 注释）
- ~~选项无 `_name` 时输出 "option N" 占位~~ → **已修**（回退到首字段值）
- ~~Apple 页标题/价格被步骤块压后~~ → **已修**（标题与事实先于主指块）
- compare 网格溢出风险（DETAIL 角标压字）→ **已修 CSS**（允许换行）
- 主次倒置的通病（根动作沉底、hero 无构图）→ 引擎 prior 库任务，非一轮可毕
- 角色标签（MEASURE/PRICE）直接可见、同一费率拆成三行 → 基线可接受，"价格行合并"进 prior 库

**Judge 错误一处（已核验）**：judge 1 称 antd 嵌套成绩 98/60/70 未渲染——经 HTML 核验**存在**（位于行内操作单元格，截图密度高导致误读）。

## 5. 边界与未竟事项

- **单 judge、未经人工校准**——judge 与人的一致性尚未测；在人工抽检确认前，judge 分数只作方向参考，不进覆盖率声明（§7 纪律）。
- aliyun 的 dom/a11y 抓取为单行长文件，judge 只能在截图分辨率上核验部分金额。
- 6 页是 exemplar 集；覆盖率声明（99% 顶流）仍需 M3 在冻结快照上规模计算。
- hold-out 集未动，保持到语法冻结。

# 付款 | Stripe 文档

## 使用 Stripe 开始接受支付。

与 Stripe 集成，开始接受在线和当面付款，嵌入金融服务，使用自定义营收模型，并确定哪些 Stripe 产品最适合您的业务需求。

[查找您的用例](https://docs.stripe.com/payments/use-cases/get-started)

## 支付选项

- **[线上收款](https://docs.stripe.com/checkout/quickstart)**: 创建支付表单或使用预构建支付页面来接受线上付款。
- **[创建订阅](https://docs.stripe.com/billing/quickstart)**: 为您的 SaaS 或电商业务设置定期开单。

## 支付之外

- **[成立公司](https://docs.stripe.com/atlas)**: 使用 Stripe Atlas 在世界上大多数地方创办美国公司。
- **[集成加密货币](https://docs.stripe.com/crypto)**: 让您的用户以加密货币支付、以加密货币提现，或嵌入法币兑加密货币入金系统。
- **[Financial Connections](https://docs.stripe.com/financial-connections)**: 从用户的财务账户中访问授权的数据。

## 平台和市场

### [构建 SaaS 平台](https://docs.stripe.com/connect/saas)

建立 Connect SaaS 平台，为直接向其客户收款的商家提供平台服务。

### [构建交易市场](https://docs.stripe.com/connect/marketplace)

设置一个 Connect 交易市场代收客户款项，并将一部分支付给卖家或服务提供者。

### [充值并发送提现](https://docs.stripe.com/global-payouts)

直接以当地货币向您的卖家或服务提供商发送资金。

标签: 无需代码

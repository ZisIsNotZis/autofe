# Amazon EC2 按需定价

## 数据传输

AWS 客户每月可免费将 100GB 的数据传出至互联网，所有 AWS 服务和区域（中国区域和 GovCloud 区域除外）合并计算。100GB 免费传出至互联网的数据额度全球适用，不单独或分别适用于 AWS 区域。

|  | 定价 |
| --- | --- |
| 数据自互联网传入 Amazon EC2 |  |
| 所有传入数据 | 每 GB $0 |
| 数据自 Amazon EC2 传出至互联网 |  |
| 每月前 10TB | 每 GB $0.09 |
| 每月随后的 40TB | 每 GB $0.085 |
| 每月随后的 100TB | 每 GB $0.07 |
| 每月超出 150TB 的部分 | 每 GB $0.05 |

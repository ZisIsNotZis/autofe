VLOOK™ Typora Markdown
VLOOK™ 是针对 Typora 的主题包和增强插件，旨在与众 Markdown 粉共创 Markdown 文档的新看(wán)法。
当我们将系统或浏览器开启 Dark Mode（夜间模式）后，图片显示得有点不太和谐，怎么办？
以「反色」方式进行适配
在 Dark Mode 时以「反色」方式显示图片，一般适合黑/灰白图片。
以「替换」方式进行适配
以「替换」方式为深色模式指定另一张图片，适合带品牌色的彩色图片。

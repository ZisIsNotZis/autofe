# M2 Judge Rubric（意图层对照）

判定对象：原页面截图 vs 我们渲染的截图 + 产生渲染的模型（即声明的意图）。
判定原则：**只判语义，不判美学**——渲染器是刻意朴素的品牌无关基线；像素/风格差异不计分。

## 维度（每维 0 / 1 / 2，必须附一条来自截图的具体证据）

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| D1 信息覆盖 | 原页的重要事实大量缺失 | 部分缺失 | 语义等价齐全（名称/选项/价格/规则） |
| D2 主次强调 | 主旨被埋没 | 有主旨但弱于原页 | 与原页相同的主 takeaway 视觉主导 |
| D3 故事线顺序 | 顺序错乱妨碍理解 | 基本可读但有倒置 | 与原页一致的阅读/步骤顺序 |
| D4 动作可供性 | 关键动作缺失 | 动作少或主体错 | 同类动作齐全且主体一致 |
| D5 无捏造 | 出现原页没有的事实/选项 | 轻微越界 | 全部有据 |
| D6 意图保持 | 达不成模型声明的 `_intent` | 勉强 | 用户能据此达成意图 |

## 事实保真分母口径（`m1/eval/metrics.mjs`，2026-10-01 收紧 · F-052）

确定性度量不替代 judge，但它报出的「保真 1.00」必须写清分母。**分母 = 模型里所有应渲染的文本值**：

| 来源 | 计入 | 说明 |
|---|---|---|
| role 事实（`_name`/`_title`/`_price`…） | `text`/`date` 字面；`money` → 数值；`num` → 数值；`list` → 逐元素递归 | 与渲染器 `fmt()` 的取值面一致 |
| `_fields` 条目（表格单元格） | 同上（`text`/`date`/`money`/`num`/`list`） | F-052 前只算 `text`/`date`/`num`，`money`/`list` 漏项 ⇒ 表格式页面分母偏小、覆盖被高估；现走同一 `pushFact` 遍历 |
| `_intent`、`_key`、`_when`、`_expose`、`_rel`、`_action`、`_empty` | **不计** | 内部语义 / 非文本事实，渲染器刻意不外显（见 `axioms-v0`、`layout-axes`） |
| `bool`/`image`/`video`/`icon`/`ref` 值 | **不计** | 非文本事实；`ref` 是页内锚点，不是源页文案 |
| `_when` 判死子树的 role 事实与 `_fields` 条目 | **不计** | 条件不成立的节点不渲染，计入会制造假缺失；数量单独报为 `conditionSuppressedFacts` |
| `<style>`/`<script>` 主体、标签属性里的文本 | **不计**（不可见内容不作证） | F-054 收紧：`margin:0`、`class="depth-0"` 不能为一格 `0` 作证 |

匹配方式为规范化子串包含（`norm`：小写、去标点/空白、解 HTML 实体），**但命中必须成词（2026-10-01 收紧 · F-054）**：

**「已渲染」判定口径**：值的规范化文本在渲染页的**可见文本**里出现，且该次出现的**任一侧都不被同类的延续字符接上**。

| 项 | 规则 |
|---|---|
| 可见文本 | `<style>`/`<script>` 主体与**标签属性**不算内容（`margin:0`、`class="depth-0"` 不能为一格 `0` 作证）；标签折叠为 `<>` 仍作分隔符 |
| 命中边界 | 逐次命中查**原始 HTML** 相邻字符；取「值自己的**边界字符类别**」决定禁止的邻接类 |
| 数字边界 | 值为数字结尾/开头 ⇒ 邻接数字不得（`,` `.` 仅当其后/前也是数字时算延续，因此句末句点、`$0`、`870人` 均可） |
| 词边界 | 值为非数字结尾/开头 ⇒ 邻接**字母**不得（`Save` 命中 `Savechanges` 不算；命中 `Save changes` 算） |
| 其他 | 空白/标签/符号（`$ % ° - : ( )`）与值自身的标点都是分隔符；`norm` 与逻辑不变，多词值仍跨标点/标签匹配 |

已知残余局限（未修，行文如实）：
- **字母紧贴的数字**仍算命中（`0` 命中 `ID0`、`18` 命中 `padding-left:18px` 形态的**正文**）：字/数混排词（多为带单位的量）无法与「值确实是子串」区分——收紧它会把 `870人`、`2 vCPU` 判成假缺失（实测反例见 `.scratch/14-match-precision/report.md` §1）。
- 度量仍是**路径无关**的：同一页面若有两个值相同的格，其中一格真缺、另一格渲染了，本口径只报「已渲染」（多数表述模型无重复值，aws 的 2 个 `$0` 是已知例外）。
- `ref`/`image` 等非文本事实本来就不在分母内，其 URL 是否渲染不受本口径约束。

## 每页必产出的关键判断

最重要的产出不是分数，而是**缺口归属**：
- **MODEL gap**——中间表示表达不了（→ 失败日志，驱动语法/词表演进）
- **RENDERER gap**——模型里有，朴素基线没呈现好（→ 引擎 prior 库）

## 纪律

- 逐维度分开问，不做总评打分（pairwise 优于绝对分，见 design-basis §7）
- 能确定性测的（事实保真、故事线秩）不进 judge——见 `m1/eval/metrics.mjs`
- judge 须用人工标注样本校准并报告一致性后，结果才能进入覆盖率声明

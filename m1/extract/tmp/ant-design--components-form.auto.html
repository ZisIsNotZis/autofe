Why can't Switch, Checkbox bind data?

How does name fill value when it's an array?

textname will fill value by array order. When there exists number in it and no related field in form store, it will auto convert field to array. If you want to keep it as object, use string like: ['1', 'n

Why is there a form warning when used in Modal?

summaryWarning: Instance created by useForm is not connect to any Form
textBefore Modal opens, children elements do not exist in the view. You can set forceRender on Modal to pre-render its children. Click here to view an example.

Why is component defaultValue not working when inside Form.Item?

textComponents inside Form.Item with name property will turn into controlled mode, which makes defaultValue not work anymore. Please try initialValues of Form to set default value.

Why can not call ref of Form at first time?

summaryref only receives the mounted instance. please ref React official doc: https://react.dev/learn/manipulating-the-dom-with-refs#when-react-attaches-the-refs

Why will resetFields re-mount component?

summaryresetFields will re-mount component under Field to clean up customize component side effects (like async data, cached state, etc.). It's by design.

textgetFieldsValue returns collected field data by default, but the Form.Item node is not ready at the first render. You can get all field data by getFieldsValue(true).

如何在 Next.js 中使用主题包
  • 首先安装插件 npm i @douyinfe/semi-next (如果你使用 yarn 或 pnpm，请自行更换为对等命令)
  • 在 next.config.js 中进行配置，插件会将组件默认的import CSS 语句移除。更多配置可查阅 @douyinfe/semi-next详细文档详细文档
  • 在 global.css 中引入全量的 semi css（目前在 Next.js 中不支持按需引入）

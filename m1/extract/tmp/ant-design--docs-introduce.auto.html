Ant Design of React

textFollowing the Ant Design specification, we developed a React UI library antd (Pronunciation ) that contains a set of high quality components and demos for building rich, interactive user interfaces.

Installation

Using npm or yarn or pnpm or bun

summaryIf you are in a bad network environment, you can try other registries and tools like cnpm.
textWe recommend using npm or yarn or pnpm or bun to install, it not only makes development easier, but also allow you to take advantage of the rich ecosystem of JavaScript packages and tooling.

Import in Browser

summaryAdd script and link tags in your browser and use the global variable antd.
textWe provide antd.js and antd.min.js reset.css under dist folder in antd's npm package. You can also download these files directly from , or unpkg.
textWe strongly discourage loading the entire files this will add bloat to your application and make it more difficult to receive bugfixes and updates. Antd is intended to be used in conjunction with a build tool, such as webpack, which will make it easy to import only the parts of antd that you are using.
textNote: You should import react, react-dom, dayjs before using antd.js.

Companies using antd
